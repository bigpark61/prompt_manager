# 프롬프트 관리 프로그램

콘솔에서 자주 사용하는 프롬프트를 등록하고 관리하는 프로그램입니다.
프롬프트 정보와 즐겨찾기 상태는 프로그램 폴더의 `prompts.json` 파일에 저장됩니다.

## 주요 기능

- 프롬프트 추가
- 전체 프롬프트 목록 보기
- 카테고리별 조회
- 제목, 카테고리, 내용 기준 검색
- 프롬프트 상세 보기
- 즐겨찾기 등록 및 해제
- 즐겨찾기 목록 보기
- 프롬프트 수정
- 프롬프트 삭제
- 목록 제목순 정렬

## 메뉴

| 번호 | 기능 |
| --- | --- |
| 1 | 프롬프트 추가 |
| 2 | 전체 목록 보기 |
| 3 | 카테고리별 조회 |
| 4 | 프롬프트 검색 |
| 5 | 상세 보기 |
| 6 | 즐겨찾기 등록/해제 |
| 7 | 즐겨찾기 목록 보기 |
| 8 | 프롬프트 수정 |
| 9 | 프롬프트 삭제 |
| 0 | 프로그램 종료 |

## 실행 방법

### 1. Python 설치 확인

Python 3.10 이상이 설치되어 있어야 합니다.

```powershell
python --version
```

### 2. 프로그램 폴더로 이동

PowerShell에서 프로그램 파일이 있는 폴더로 이동합니다.

```powershell
cd "프로그램이 저장된 경로\prompt_manager"
```

### 3. 프로그램 실행

```powershell
python prompt_manager.py
```

실행 후 메뉴 번호를 입력하면 해당 기능을 사용할 수 있습니다. 각 기능을 완료하면 Enter 키를 눌러 메뉴로 돌아갑니다.

## 데이터 저장

- 프롬프트 데이터는 `prompts.json`에 저장됩니다.
- 프롬프트를 추가, 수정, 삭제하거나 즐겨찾기를 변경하면 즉시 저장됩니다.
- `prompts.json`이 없거나 형식이 올바르지 않으면 기본 프롬프트 데이터로 다시 생성됩니다.
"# prompt_manager"
